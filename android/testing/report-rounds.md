## 客观判据（避免"看起来对"）

- **封面是否真加载** → `dumpsys notification --noredact` 中 `android.largeIcon=` 非 `null`（实测 `Icon(typ=BITMAP size=168x168)`）
- **播放状态** → `dumpsys media_session` 中 `state=PlaybackState`（`grep -oE 'state=[A-Z]+'` 会误匹配类名 `PlaybackState`，必须先定位该行）
- **崩溃检测** → 普通 logcat 只有 `reason=4 (APP CRASH)`，完整 Compose 栈必须读 `adb logcat -b crash -d`
- **截屏** → `adb shell screencap -p /sdcard/s.png` + `adb pull`（Git Bash 下 `exec-out` 会因换行符转换产出全黑图）
