## 1. 产品定位

qMusic 是一款**在线音乐播放器 Android App**，产品形态参考字节跳动早期「汽水音乐」：
- **轻量、沉浸、情绪化**：打开即听，首页即推荐，不强调复杂功能；
- **视觉鲜明**：浅色首页 + 深色全屏播放页，大封面 + 毛玻璃 + 渐变；
- **内容驱动**：以「每日推荐」和「歌单」为核心分发入口，配合搜索找到任意歌曲。

### 1.1 目标用户
- 通勤/学习/运动时希望「打开就放」的轻度音乐用户；
- 喜欢干净界面、大封面、沉浸式播放体验的用户。

### 1.2 一句话描述
> 一款「首页即推荐、点开就能听、播放页好看得让人不想退出」的在线音乐播放器。

### 2.1 用户故事

| 角色 | 用户故事 | 优先级 |
| --- | --- | --- |
| 听众 | 我打开 App 就能看到今日推荐并直接播放 | P0 |

| 听众 | 我想把喜欢的歌加入「我喜欢的」列表 | P1 |

### 2.3 非功能需求
- **性能**：冷启动 < 3s；列表滑动 60fps；播放地址获取 < 1s。
- **网络**：弱网下显示加载态与错误重试；歌曲地址超时自动重试。
- **兼容**：minSdk 26（Android 8.0），targetSdk 35。
- **版权合规**：仅接入第三方平台公开试听接口，不提供下载与 VIP 解锁，项目仅用于学习。

## 3. 竞品参考：早期汽水音乐

「汽水音乐」是字节跳动于 2022 年推出的音乐产品，其早期版本的设计特征：

| 特征 | 说明 | 在本项目的落点 |
| --- | --- | --- |
| 首页即推荐 | 打开 App 首页即是一张巨大的「每日推荐」卡片 | 发现页 Hero 卡片 |
| 大封面 | 封面图占据视觉中心，背景与封面联动 | 播放页 300dp 圆盘封面 + 模糊渐变背景 |
| 深色播放页 | 播放页为深色沉浸式，与浅色列表页形成反差 | 播放页使用 `#141418` 深色 |
| 底部三栏导航 | 发现 / 播放 / 我的 三个主导航 | TabBar 三栏，中间为播放 |
| 常驻播放条 | 列表页底部始终有当前歌曲迷你播放条 | 迷你播放条 + 进度条 |
| 歌词视图 | 播放页可切换到全屏歌词 | 播放页内嵌歌词视图 |

> ⚠️ 本项目为**参考风格**的原创实现，不复制汽水音乐的图标、文案与素材。

## 5. UI/UX 设计

### 5.1 视觉风格
- **关键词**：轻量、清爽、沉浸、年轻化、大圆角、渐变点缀。
- **明暗对比**：列表页浅色（`#F7F7F9`），播放页深色（`#141418`），切换时形成「沉浸式进入播放」的仪式感。

### 5.2 色彩规范

| Token | 色值 | 用途 |
| --- | --- | --- |
| `accent` | `#FF4B4B` | 主强调色：按钮、进度、红点 |
| `accent2` | `#FF8A3D` | 渐变辅色：Hero、按钮 |
| `gradient` | `linear-gradient(135deg,#FF4B5C,#FF8A3D)` | 品牌渐变（Logo、播放按钮） |
| `bg` | `#F7F7F9` | 页面背景（浅色） |
| `card` | `#FFFFFF` | 卡片背景 |
| `text` | `#15161A` | 主文字 |
| `text2` | `#8A8A93` | 次要文字 |
| `line` | `#F0F0F2` | 分割线/描边 |
| `dark` | `#141418` | 播放页背景 |
| `dark2` | `#232329` | 播放页控件底色 |

### 5.3 字体
- 系统字体栈：`-apple-system, "PingFang SC", "HarmonicOS Sans SC", "Microsoft YaHei", sans-serif`
- 字号层级：页面标题 19px / 区块标题 17px / 歌曲名 15px / 次要信息 12px / 角标 10.5px

### 5.4 圆角与间距
- 卡片圆角：16–22px；按钮圆角：胶囊（999px）
- 页面左右边距：16px；区块间距：18px

### 5.5 组件规范

| 组件 | 规范 |
| --- | --- |
| 底部导航 | 高 64px，3 个 Tab，图标 21px + 文字 10.5px，选中态深色 |
| 迷你播放条 | 距底部 70px，高 58px，圆角 18px，深色半透明毛玻璃，底部 2px 渐变进度条 |
| Hero 卡片 | 圆角 22px，封面 104px 圆角 18px，背景深紫→玫红渐变，右上角光斑 |
| 歌曲项 | 封面 46px 圆角 10px，歌名 15px/600，歌手 12px 灰色，右侧播放量+更多 |
| 播放控制 | 主按钮 68px 白底圆，次按钮 46px，图标型 |
| 进度条 | 高 4px，圆角，已播放部分品牌渐变，白色圆形滑块 12px |

### 5.6 原型说明

高保真可交互原型位于 `prototype/index.html`，用浏览器直接打开即可体验：
- 点击「发现页」歌曲 → 打开播放页；
- 点击迷你播放条 → 展开播放页；
- 播放页右上角「📄」→ 切换歌词视图；
- 点击搜索图标 → 搜索页（输入关键词可实时过滤）；
- 底部导航切换「发现 / 播放 / 我的」。

## 6. 关键交互流程

### 6.1 播放主流程
```
启动 App
  → 发现页展示每日推荐 + 为你推荐
  → 点击歌曲 / 点击 Hero 播放按钮
  → 底部弹出迷你播放条（若为首次播放）
  → 进入全屏播放页（深色背景 + 圆盘封面）
  → 点击 播放/暂停 切换；点击 下一首/上一首 切歌
  → 点击 歌词 切换歌词视图，当前行高亮
  → 下拉/点击 收起 返回发现页，迷你播放条持续显示
```

### 6.2 搜索流程
```
点击搜索图标
  → 搜索页（显示历史 + 热搜）
  → 输入关键词，实时过滤结果列表
  → 点击结果项 → 播放该歌曲并返回发现页
```

### 6.3 收藏流程
```
播放页点击 ❤️
  → 本地写入 Room（I LIKE 表）
  → 我的页「我喜欢的」列表即时更新
```
