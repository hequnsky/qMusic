### APK 命名规则

```
<appName>-<versionName>-<buildType>.apk
qMusic-1.03-release.apk        # 生产包（已签名 + R8）
qMusic-1.03-debug.apk          # 调试包
```

每次打包 `versionName` **+0.01**、`versionCode` **+1**（见 `android/version.properties`），
所以每个 APK 的版本号天然唯一，装机后可直接对照是哪一次构建。

## 3. 服务端部署（音乐抓取服务）

```bash
cd server
npm install        # 安装依赖（首次）
npm start          # 启动服务
```

- 默认地址：`http://localhost:3000`
- 验证：浏览器打开 `http://localhost:3000/search?keywords=海阔天空`，应返回 JSON。
- 修改端口：`set PORT=4000 && npm start`（Windows）或 `PORT=4000 npm start`（macOS/Linux）。
- Windows 双击 `start.bat`、macOS/Linux 执行 `./start.sh` 亦可。

### 3.1 让 Android 访问到服务

| 运行方式 | 服务端地址 | 说明 |
| --- | --- | --- |
| Android 模拟器 | `http://10.0.2.2:3000` | 模拟器内访问宿主机专用地址 |
| 真机（同一局域网） | `http://<电脑IP>:3000` | 需修改 App 中 `BASE_URL` 与网络安全白名单 |

## 4. Android 构建

### 4.1 命令行构建

```bash
cd android

# 首次构建自动下载 Gradle（本机已缓存则秒级完成）
./gradlew assembleDebug
```

> 若 `services.gradle.org` 下载超时（国内网络常见），可直接使用本机 Gradle 缓存构建：
>
> ```powershell
> $gradle = "$env:USERPROFILE\.gradle\wrapper\dists\gradle-8.13-bin\<hash>\gradle-8.13\bin\gradle.bat"
> & $gradle -p "F:\project\AiCoding\deepseek\qMusic\android" :app:assembleDebug --no-daemon
> ```
>
> 其中 `<hash>` 为 `%USERPROFILE%\.gradle\wrapper\dists\gradle-8.13-bin` 下的实际目录名。

产物：`android/app/build/outputs/apk/debug/app-debug.apk`（约 22MB）

### 4.2 Android Studio 构建
1. `File → Open` 选择 `android/` 目录；
2. 等待 Gradle Sync 完成；
3. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`。

### 4.3 配置服务端地址
默认 `BASE_URL = http://10.0.2.2:3000`（模拟器）。
真机调试时：
1. 修改 `app/src/main/java/com/qmusic/data/remote/ApiClient.kt` 中 `BASE_URL` 为电脑局域网 IP；
2. 同步修改 `app/src/main/res/xml/network_security_config.xml` 中 `<domain>` 为对应 IP。

### 4.4 Release 签名构建

签名配置从 `android/local.properties`（已 gitignore，不入库）读取，也支持环境变量（`QMUSIC_STORE_FILE` 等）：

```properties
# android/local.properties
qmusic.storeFile=qmusic.keystore
qmusic.storePassword=<密码>
qmusic.keyAlias=qmusic
qmusic.keyPassword=<密码>
```

生成密钥并构建：

```bash
keytool -genkey -v -keystore android/qmusic.keystore -alias qmusic \
  -keyalg RSA -keysize 2048 -validity 3650 -storepass <密码> -keypass <密码> \
  -dname "CN=QMusic, OU=Dev, O=QMusic, L=Beijing, ST=Beijing, C=CN"

cd android
./gradlew assembleRelease
```

产物：`android/app/build/outputs/apk/release/app-release.apk`（约 15MB，正式签名）。
验证签名：`apksigner verify --print-certs android/app/build/outputs/apk/release/app-release.apk`

> 说明：`app/build.gradle.kts` 中已配置 `lint { checkReleaseBuilds = false }`，保证无 lint 阻塞的可复现构建。

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

或直接把 APK 拷贝到手机点击安装（需允许「未知来源」）。

- 启动 AVD（建议 API 30+），确认服务端已在宿主机运行；
- 安装 APK 后打开 App，发现页应加载出推荐内容。

### 5.2 真机
- 手机与电脑连同一 Wi-Fi；
- 按 4.3 修改服务端地址并重新打包；
- 安装运行。

## 7. 常见问题

### Q1: App 能打开但列表/播放失败？
- 确认服务端已启动：浏览器访问 `http://localhost:3000` 应返回页面。
- 模拟器请使用 `10.0.2.2`，真机请使用局域网 IP 并在手机浏览器先访问验证。

### Q2: 播放提示「无法连接到服务器」？
- 检查 App 是否使用 `http://` 明文地址：已通过 `network_security_config` 放行 `10.0.2.2` 与 `127.0.0.1`；
- 真机场景需把电脑 IP 加入白名单（见 4.3）。

### Q3: 部分歌曲点击播放无声音？
- 第三方平台对部分歌曲（VIP/下架）不返回播放地址（`url` 为 null）；
- 属正常现象，请换一首歌曲验证。

### Q4: 构建时 Gradle 下载慢/失败？
- 本机已缓存 Gradle 8.13；若需下载，建议配置国内镜像（阿里云 maven）：
  `settings.gradle.kts` 中替换 `google()` / `mavenCentral()` 顺序或添加镜像仓库。

### Q5: 通知栏不显示封面？
- 需要通知权限（Android 13+ 动态申请）；封面由 Coil 异步加载，弱网时可能延迟。
